# 0.3.0 遥控功能与首轮实测

适用当前 ESP32-C6-Touch-LCD-1.47、Sony A7 IV（ILCE-7M4），目标固件1.01。新增功能已经实现，编译/主机结果另见验证记录；本说明中的相机步骤均待用户实测。0.2.2只有连接及控制获得了用户反馈，不能替代本轮验收。

## 更新和菜单

Arduino IDE 打开 [CameraCompanion.ino](../CameraCompanion/CameraCompanion.ino)，沿用 C6、核心3.3.12、GFX1.6.9、USB CDC、8MB/default_8MB。版本应显示0.3.0。本轮没有修改板级引脚、JD9853初始化、配对参数或NVS格式，已有配对先正常重连，不要求清除密钥。

桌面点击索尼图标直接进入第一页，提供拍照、间隔拍摄、对焦三个156×64大按钮。左滑进入下一功能页，右滑上一页：①拍摄，②录像，③手动调焦，④蓝牙变焦，⑤AF-ON/C1，⑥连接管理。首尾不循环，不会横滑切换品牌，底部显示页码并返回桌面。间隔计划、参数、配对说明和扫描结果属于详情页，右滑/底部逐级返回。录像等页面的卡片箭头可管理连接，连接后回原操控页。

## 录像与真实状态

1. 暂时退出会自动连接相机的手机App；板子连接成功后，把机身切至视频模式，确认存储卡及正常录制条件。
2. 进入录像页。初次尚无FF02录像通知时，状态必须显示“录像状态未知”，不能把连接成功解释成未录像。
3. 未知状态的按钮为“发送录像键”。它模拟完整的一次REC按下/松开，可能开始，也可能停止机身已经在进行的录像；先核对机身画面。若想先同步，可在机身手动开始/停止一次，观察板子状态是否跟随。
4. 收到 `02 D5 20` 才显示“正在录像”和红色相机图标；收到 `02 D5 00` 才显示“录像已停止”。已知状态的按钮随之变为停止/开始录像。正在录制时显示“录制 时:分:秒”，停止、状态未知或断开后不显示时长，也不显示“回报多少秒前”。计时从首次收到本次录像中的通知起算，重复录像中通知不重置，切页后继续；等待停止确认时继续计时。若连接时相机已在录像，当前通知不含此前录制时长，显示的是本次连接观察到的时长。
5. 发送后显示等待确认并禁用重复操作。FF01写入ACK只能证明GATT写入完成，不能证明已经录像；6秒内没有确认变化，状态回到未知，错误码-61，不自动重试。
6. 若机身在排队/等待GPS事务期间改变录像状态，旧录像请求取消，错误码-62；重新看屏幕再决定操作。无法撤回已经发送的录像键，BLE切换命令也不是相机原生的幂等“开始/停止”接口。
7. 录像中返回桌面不会停止录像，底部可回到录像页；全局相机图标红色只来自已收到的录像中通知。断线后清为未知、重连不补发旧录像键；机身是否继续录像需看机身。

录像UP字节是松开REC，不是停止录像。BOOT只停止照片计划并释放按键，不额外切换录像；结束录像用录像页或机身。断开连接前若正在录像会提示“录像需在机身停止”，不会暗中停止录像。

## AF-ON、C1、调焦和变焦

| 页面 | 操作 | 机身/镜头条件 |
| --- | --- | --- |
| AF-ON / C1 | 点按对应按键，或按住 | 执行机身为该键分配的功能；不等于可以设置任意参数 |
| 手动调焦 | 焦点移近/移远，点按微调或按住连续 | 机身MF，镜头支持电子驱动；纯机械手动镜头不适用 |
| 蓝牙变焦 | 广角W/长焦T，点按或按住 | 电动变焦镜头或可用且已启用的机身电子变焦；机械变焦环不能靠此驱动 |

短按按下ACK后约120ms释放。长按先静止350ms才发送；移动超过手势阈值或滑出按钮会请求释放，松手/换页也请求释放。按住最长10秒，需松手后重新按；400ms续期租约用于停止没有持续触摸确认的操作，不是镜头机械响应保证。单一GATT事务必须串行；已有事务先完成，失败/4秒超时则断开并提示检查机身。

这些按键与快门计划互斥，暂停的计划也需先停止；录像中可以尝试AF-ON/C1及调焦/变焦。变焦、调焦是否实际动作以及速度/行程均需用实际镜头验证。机身开始录像会停止照片计划，不自动恢复。

## 串口诊断

115200，行结束符为新行。`help`查看命令：

```text
status
record
afon
c1
near
far
wide
tele
stop
```

除`status`外各行分别发送，不要一次粘贴整组来控制相机。`record`是一次录像键切换；其他新遥控命令都是一次有界短按。长按只由触摸页面维持，串口不允许无界保持。

`status`新增：`video=UNKNOWN/STOPPED/RECORDING`、`record_pending`、`notify`（CCCD订阅ACK）、`remote_key`、`held`、`busy`、`last_video_ms`（最近录像通知的板子运行时间）。`notify=1`并不能证明机身实际发送了录像状态；FF02有效通知才改变video。错误-60表示先结束当前操作，-61未收到录像确认，-62状态已变取消旧请求。原配对/断开诊断保留。

## 首轮实测建议

先保持模拟GPS关闭，依次验证录像开始/停止、机身录像按钮状态同步、AF-ON/C1、MF近远、变焦。每个长按都检查松手、滑出和换页后的机身行为；再开启模拟GPS复测，最后检查录像中断线/重连不会自动切换录像。不要仅根据屏幕文字认定文件成功保存，需核对机身视频文件。

反馈请提供0.3.0的`status`输出、机身实际状态、镜头型号/AF-MF开关及哪一项无效；不需要发送配对码、真实位置或其他个人配置。勾选 [实物清单](HARDWARE_TESTS.md) 时保留版本和证据。
