# 公开包与隐私检查

发布目录按明确文件清单创建，没有复制本地工程的完整目录、Git历史、运行设备存储、原始串口/编译日志、真实设备截图或配置备份。说明和验证记录重新整理为公开版本，不含本机用户名、绝对环境路径、设备地址或账户资料。

包含源码、模拟测试、原创图标、开放字形、通用操作说明和必要的第三方许可证。协议中固定的测试坐标、测试名称/码、UUID和版本号不是实际用户数据；上游公开作者署名依法保留。

可以重新检查源码树或最终ZIP：

```text
python tools/privacy_audit.py --self-test
python tools/privacy_audit.py --archive path/to/source.zip
```

检查器只报告文件名和类别，不打印匹配值；覆盖路径、设备地址、常见凭据、改名后的配置JSON、未审文件类型、图片元数据和ZIP路径/CRC。它也会核对当前运行环境的长用户名/机器名标记。清单和扫描是本次发布检查，不能保证未来添加的任意文件安全。

`PUBLIC_MANIFEST.json`列出除清单本身外的发布文件、大小和SHA-256。压缩包使用统一时间和权限元数据，不携带本地文件时间、所有者或额外字段。

未来提交问题日志、照片、设备截图或自己的配置前，仍须检查其中的相机名称、定位、日期、地址和密钥。`.gitignore`只是辅助，不能替代审查。不要将整个本地开发目录替换为本公开包上传。
