# 实物验收清单

当前版本0.3.0，目标为ESP32-C6-Touch-LCD-1.47及Sony A7 IV / ILCE-7M4、固件1.01。此前0.2.2的连接及相机控制已有使用反馈；本清单逐项结果仍需记录，公开OFL字体尚未上板复验。

## 第一轮：显示和连接

- [ ] 选择 ESP32C6、8MB/default_8MB、USB CDC；记录实际核心、库和上传时间。
- [ ] 开机无闪屏/花屏，中文可读，圆角与图标自然；顶部电池电压与万用表比对。
- [ ] 桌面五个入口正确：索尼/大疆/尼康/设置/GPS设置。大疆与尼康只有待开发提示，不触发无线控制。
- [ ] 索尼入口直达拍摄；第1页拍照/间隔/对焦，第2页录像，其后调焦、变焦、AF-ON/C1、连接。横滑不切品牌，首尾不循环，页码和返回桌面正确；间隔详情仍逐级返回，顶部实物对齐一致。
- [ ] 从按钮开始滑动、滑出再回、长按都不执行拍照；正常轻点只执行一次。
- [ ] 扫描能发现处于配对状态的相机。
- [ ] 当前公开版本正常连接，分别记录实际遥控动作和文件保存结果。
- [ ] 若出现数字比对，双方数字一致后板上确认、机身确认；不一致/取消/等待超时都不能配对。滑动和提示前开始的触摸不误确认，断开不残留PIN。
- [ ] 手机退出连接后可配对；BLE 配对记录保存，板子重启可恢复。

## 第二轮：拍摄

- [ ] 照片/单张模式，单拍一次并核对相机保存文件；对焦操作不额外拍摄。
- [ ] AF/MF 下短暂对焦行为符合机身设置，状态通知/超时正确。
- [ ] 10 张、5 秒间隔，统计实际文件数和触发时间；核对「已发」与落盘的差异。
- [ ] 参数菜单直达间隔/张数/更多，增减在边界停止，持续拍摄须显式选择；返回父页不丢配置。
- [ ] 设置启动延时、每张对焦、持续拍摄，确认运行页使用已提交参数；桌面状态入口可返回运行页。
- [ ] 命令防重复、正在启动时停止、断开拍摄确认/取消，以及任务完成后的返回路径正确。
- [ ] 暂停/恢复/停止及 BOOT 停止，在对焦、按下、等待、定位写入时分别检查，无卡住按键或补拍。
- [ ] 相机忙、对焦失败、存储卡忙时正确报错/跳过，无快门突发重试。
- [ ] 拍摄中断线后停止，重连不会自动拍摄；观察至少一小时的内存、响应和稳定性。

## 第三轮：定位与重连

- [ ] 模拟 GPS 默认关闭，只有显式开启后写入；坐标逐步变化，无非有限值/无效日期。
- [ ] 普通单拍及间隔拍摄时同时发送 GPS，核对照片 EXIF 经纬度与预期轨迹。
- [ ] 相机照片时间没有被本工程主动修改，确认相机如何使用包中测试 UTC。
- [ ] 模拟失去信号/恢复、关闭发送，记录相机是否缓存最后位置。
- [ ] Auto 能否工作；如失败，分别验证 Legacy/Modern，记录差异，不能仅记录「服务存在」。
- [ ] 板子保持开机，相机关机 5 秒、60 秒、5 分钟后开机；记录到 Ready、定位恢复的耗时及是否需要机身确认。
- [ ] 板子重启自动连；手机曾连接后板子能否恢复；检查密钥失效与相机删除配对的处理。
- [ ] 手动断开取消重连；拍摄停止保留重连；忘记配对只影响当前保存相机，不影响其他用户配置。

## 第四轮：0.3.0 新遥控（全部待测）

具体步骤见 [遥控功能说明](REMOTE_CONTROLS.md)。记录镜头型号、机身AF/MF及电子变焦配置；先关闭模拟GPS，再复测共存。

- [ ] 桌面直达索尼拍照/间隔/对焦；第2页录像，其后调焦/变焦/按键/连接，反向逐页返回、首尾停住。从拍照按钮开始横滑不拍照。
- [ ] 索尼功能页底部回桌面，间隔详情逐级返回；设置/GPS只在自身功能横滑，待开发品牌不横滑跳应用。
- [ ] 相机切视频模式，初连无通知显示UNKNOWN/录像状态未知；不能仅凭连接或rc_acks认定未录像。
- [ ] 板上一次录像键使机身实际开始并保存视频；收到回报才显示正在录像、顶部相机红色；停止后机身停止且收到STOPPED。
- [ ] 在机身手动开始/停止，板子随FF02同步；录像页显示“录制 时:分:秒”，停止/未知/断开后隐藏时长，无“回报多少秒前”。重复录像通知和切页不重置计时，等待停止确认时仍计时；若连接前已在录像，不把连接后观察时长当成影片总时长。
- [ ] 条件不允许录像时不虚报成功；6秒无确认后未知、-61，不重复切换；待确认期间多次点击无额外录像键。
- [ ] GPS事务忙时改变机身录像状态，过时请求取消，不在延迟后误停止录像。
- [ ] AF-ON/C1点按、长按符合机身分配功能；机身MF、电子对焦镜头下近/远方向和实际动作正确。
- [ ] 电动/电子变焦可广角/长焦移动；机械变焦环不动作不能直接认定BLE故障。
- [ ] 长按前滑动不驱动；长按后松手、移出、换页、BOOT请求释放。10秒上限需重新按；释放失败/事务超时有错误并断开，核对机身实际停动。
- [ ] 暂停照片计划也与遥控互斥，先停止再操作；录像中不能启动照片计划，可尝试镜头键；机身开始录像停止原照片计划。
- [ ] 长按断线清本地按键，重连不重放旧键；录像状态清为未知。BOOT不盲目发送额外REC键，录像用录像页或机身停止。
- [ ] 返回桌面保持录像，底部能回录像页；断开确认提示在机身停止，实际录制结果核对机身和视频文件。
- [ ] 模拟GPS与录像/按住/释放共存，释放后定位恢复。原单拍、间隔、配对和关开重连分别回归。

## 后续真实 GPS

- [ ] 按模块电平、供电和板子可用引脚确定 UART 接线；USB CDC 与 Serial0 分开。
- [ ] 接入真实经纬度、UTC、定位有效性及数据新鲜度，丢星/断开后不继续发送过期数据。

填写结果时保留相机固件、菜单设置、协议/MTU、测试步骤、实际文件或 EXIF 证据和失败现象。主机模拟、编译成功或手机 App 成功均不能勾选本表实物项目。

## 第五轮：动画、整页桌面与SD GPX（全部待测）

- [ ] 左右功能切换、上下详情/桌面有短过渡；首尾轻回弹，顶部四项固定。触摸/BOOT在动画中仍响应，过渡中的新触摸不误操作。
- [ ] 桌面每次移动两个图标，0→2→4及反向正确；末页只有GPS，空位不可点，边缘不出现半格位置。
- [ ] `status`记录最近frame_ms，并在BLE连接/录像/定位/SD写入时观察；慢帧会结束动画，不把主机像素比对当实测FPS。
- [ ] 不插卡时检测失败、开始不可用；插卡检测可用后才开始，开始前重新核实。原卡文件不格式化、不删除、不覆盖。
- [ ] 开启模拟定位，GPX约1Hz、名称/元数据标记SIM，坐标/UTC/海拔符合模拟源。未开启或信号丢失显示等待，不续写过期点；恢复后分段。
- [ ] 一分钟后停止并保存，核对卡上 `/CameraCompanion/GPX/` 文件能被GPX工具读取；重复开始生成新文件、旧文件保持不变。
- [ ] 读写错误停止记录并撤销可用状态；重新插卡需检测/手动开始。拔卡/断电恢复只能记录实际结果，不承诺FAT完全无损。
- [ ] SD与LCD共用SPI时无花屏/总线争用；检测/写入期间触摸、BOOT及相机按键释放不被存储任务阻塞。慢卡的画面影响单独记录。
- [ ] 返回桌面及停止照片任务后GPX继续，点停止并保存才结束；RESET不当作保存。无卡/慢卡、动画、单拍/间隔/录像及模拟GPS共存回归。
