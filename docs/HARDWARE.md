# 硬件和运行方式

仅对应 Waveshare ESP32-C6-Touch-LCD-1.47，1.47英寸、172×320竖屏。相似ESP32/S3产品的屏幕、偏移和引脚可能不同。

| 部件 | 连接 |
| --- | --- |
| LCD / SD共享SPI | SCK1、MOSI2、MISO3 |
| LCD | JD9853，CS14、DC15、RST22、背光23，34列偏移 |
| SD卡片选 | GPIO4，4MHz；显式检测和GPX备份，与LCD共用SPI |
| I²C | SDA18、SCL19 |
| AXS5106L触摸 | 地址0x63，RST20、INT21 |
| QMI8658A IMU | 地址0x6B；本应用未启用IMU业务 |
| 电池ADC | GPIO0，按分压乘3，仅为估算电压 |
| BOOT | GPIO9，低电平，停止照片计划并释放遥控按键；不会停止录像或GPX |
| 原生USB CDC | GPIO12/13，Serial |
| 物理UART0 | GPIO16/17，Serial0；当前未占用来解析GPS |

LCD/I²C/触摸由主循环访问。BLE由独立NimBLE host任务处理，界面读取受保护快照，命令进入有界队列。停止走独立标志，避免队列满时无法停止。

SD文件操作在独立任务内执行，LCD/SD共用SPI互斥锁，显示以非阻塞方式取锁；存储忙时暂缓传输，触摸和BOOT主循环仍可运行。慢卡对画面刷新有影响，尚未实测持续FPS；GPX使用方法见[GPX说明](GPX.md)。

显示使用40行、13,760字节RGB565缓冲及变化条带发送，保留JD9853专用初始化；没有分配完整双帧缓冲。

功能翻页约220ms缓动，首尾约180ms、14像素回弹；状态栏固定。字形和画面按条带裁剪，最近整帧处理超过90ms则提前结束动画。主机像素比对只检查绘制结果，不能代替真实触摸与LCD观感。

目前没有接入真实GPS模块。接线前应按模块电平、供电、硬件版本和本板可用引脚重新核对，不把USB串口当作UART0，也不因标称电压直接推断模块兼容。
